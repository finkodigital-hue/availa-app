## Open-source software notice review

The website now publishes a generated [`third-party-notices.txt`](../public/third-party-notices.txt) covering 299 production package/version records. `npm run notices:check` compares it with the committed lockfile on every launch build, so dependency changes cannot silently leave the notice stale. The generated file includes every licence text present in the installed packages and records the declared licence and source for packages whose published archive omitted a licence-text file.

The 27 September 2026 inventory found no missing licence labels. It includes four bundled font packages under OFL-1.1 and `lightningcss` under MPL-2.0. Twenty-two package archives declared a licence but contained no standalone licence-text file; these metadata-only records and the actual browser/server distribution still require qualified review. The notice is evidence and disclosure, not a legal compatibility opinion.
